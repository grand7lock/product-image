1시작하기 — API 키 (처음 쓰는 분 상세 가이드)

AI 기능(상품명 다듬기, 카피, 검색태그, 이미지 생성)을 쓰려면 구글의 API 키가 필요합니다. 키는 "구글 AI를 쓸 수 있는 출입증" 같은 것으로, 한 번만 발급받아 생성기에 저장해두면 됩니다. 키 없이도 엑셀 업로드 · 사진 삽입 · 대표 원본 채우기 · 사이즈컷 합성 · 저장은 모두 작동합니다.

1단계. 구글 AI 스튜디오 접속

  1. 크롬에서 aistudio.google.com/apikey 접속 (이 링크가 바로 키 관리 화면입니다)
  2. 구글 계정으로 로그인 — 지메일 계정이면 됩니다. (회사 계정은 관리자가 API를 막아둔 경우가 있으니 안 되면 개인 계정 사용)
  3. 처음 접속이면 약관 동의 화면이 나옵니다 → 동의하고 진행

2단계. API 키 만들기

  1. 키 관리 화면(한국어면 좌측 메뉴 "API 키")에서 우측 상단 API 키 만들기 (영어: Create API key) 클릭
  2. 프로젝트를 고르라고 하면 "새 프로젝트에서 생성" 선택 → 잠시 후 AQ. 또는 AIza로 시작하는 긴 문자열이 만들어집니다 — 이것이 키입니다
  3. 키 오른쪽의 복사 아이콘(📋)을 눌러 복사
키는 비밀번호처럼 취급하세요 — 카톡·문서에 공유하지 말고, 각자 자기 키를 발급받는 것을 권장합니다. 키가 유출되면 그 사람이 쓰는 요금이 내 카드로 청구됩니다.

3단계. 결제 활성화 — 이미지 생성에 필수

왜 필요한가: 텍스트 기능(카피·태그·상품명)은 무료로 작동하지만, 이미지 생성은 구글이 결제 등록된 프로젝트에만 허용합니다. 카드만 등록해두는 종량제라서 등록 자체로는 요금이 나가지 않고, 이미지 1장당 수십 원씩만 청구됩니다.

  1. 같은 키 관리 화면의 키 목록에서 내 키의 "결제 등급" 열을 봅니다
  2. "무료(Free)"로 표시되어 있으면 → 그 행의 "결제 설정"(Set up billing) 버튼 클릭
  3. Google Cloud 결제 화면이 열리면: 국가(대한민국) 선택 → 카드 정보 입력 → 완료
  4. 몇 분 뒤 키 목록에서 결제 등급이 "유료(Paid)"로 바뀌면 성공입니다 (바로 안 바뀌면 5~15분 기다렸다 새로고침)
가장 흔한 실수: 결제를 A 프로젝트에 연결해놓고 B 프로젝트의 키를 쓰는 경우입니다. 키는 프로젝트에 소속되므로, 결제 등급이 "유료(Paid)"로 표시되는 바로 그 키를 복사해서 써야 합니다. 유료 프로젝트가 따로 있다면 그 프로젝트를 선택해 새 키를 만드세요.

4단계. 생성기에 키 등록

  1. 생성기 접속 → 사이드바 맨 위 "Google AI Studio API Key" 입력란 클릭
  2. 복사해둔 키 붙여넣기 (Ctrl+V) → 저장 클릭
  3. 버튼 옆에 "저장됨"이 표시되면 완료 — 다음부터는 자동으로 입력되어 있습니다
  • 키는 지금 쓰는 PC의 브라우저에만 저장되고 외부로 전송되지 않습니다. 다른 PC에서 쓰려면 그 PC에서 같은 키를 한 번 더 등록하면 됩니다 (같은 키를 여러 PC에서 동시에 써도 됩니다)
  • 키 교체: 새 키를 붙여넣고 저장. 키 삭제: 입력란을 비우고 저장
  • 공용 PC에서는 저장하지 마세요

5단계. 잘 됐는지 확인

  1. 엑셀(또는 시트)로 상품 하나를 불러온 뒤 STEP 2의 AI 문구 생성 클릭 → 문구가 생성되면 키 자체는 정상입니다
  2. STEP 3의 상세 AI 생성을 눌렀을 때 "결제 활성화 후 사용 가능" 메시지가 나오면 → 3단계(결제)가 아직 안 된 것입니다
요금이 얼마나 나가는지는 aistudio.google.com 좌측 메뉴의 사용량 / 지출에서 언제든 확인할 수 있습니다. 상품 1개 풀 작업 기준 약 400~700원 수준입니다.

2STEP 1 · 상품 정보와 가격 계산

상품을 불러오는 방법이 세 가지입니다. 셋 중 편한 것을 고르면 됩니다.

선택 1 — 엑셀로 불러오기

  • 엑셀 양식 받기로 양식을 내려받아 채운 뒤 엑셀 업로드. 한 행이 상품 1개이고 한 번에 최대 20개까지 올릴 수 있습니다.
  • 상품이 2개 이상이면 사이드바에 상품 목록이 생깁니다. 행을 클릭하면 그 상품으로 전환되고, 이미지·문구·태그·카테고리·모델 설정이 상품별로 따로 보존됩니다.
  • 각 행에 사진 수와 상태(대기 → 작업중 → 저장됨)가 표시됩니다. 미리보기 위쪽 ← 이전 다음 →으로도 이동할 수 있습니다.

선택 2 — 1688에서 한꺼번에 가져오기

  • 1688 일괄 가져오기는 1688 상품 주소만 붙여넣으면 상품명(한글)·옵션·색상·사이즈·소재·단가를 자동으로 채우고, 이미지 후보까지 가져옵니다 (최대 20개).
  • 이 기능은 PC에서 수집기가 켜져 있어야 합니다. 창 안의 수집기 다운로드로 받아 더블클릭하면 실행되고(설치 불필요), 처음 한 번 저장 폴더만 지정하면 됩니다. 켜 둔 채 쓰면 됩니다.
  • 수집기는 전용 Edge 창을 하나 띄워 1688 페이지를 실제로 열어 읽습니다. 1688이 슬라이더(안전 확인)를 띄우면 그 창이 앞으로 나오고 진행 줄에 안내가 뜹니다 — 한 번 밀어 주면 이어서 진행하고, 통과 기록이 남아 다음 상품부터는 대개 뜨지 않습니다.
  • 1688이 접속을 막으면 즉시 멈추고 15분 쉽니다(반복되면 30·60분). 남은 주소는 입력칸에 되돌아가며, 냉각이 끝난 뒤 이어서 가져오기를 누르면 멈춘 자리부터 계속합니다.
  • 가져오기가 끝나면 작업 파일이 지정 폴더(구글 드라이브 권장)에 자동 저장됩니다.
  • 도매 단가표처럼 로그인해야 보이는 정보가 필요하면, 수집기가 띄운 Edge 창에서 1688에 한 번 로그인해 두세요. 그 창에 로그인이 남아 이후 수집에 반영됩니다.
여러 PC에서 쓸 때: 수집기는 각 PC에 하나씩 받아 실행하면 되고, 작업 파일 저장 폴더를 같은 구글 드라이브 폴더로 지정하면 사무실·집 어디서든 이어서 작업할 수 있습니다.

선택 3 — 1688 한 개씩 가져오기

  • 1688 개별 가져오기는 상품 하나를 바로 넣을 때 씁니다. 1688 페이지에서 Ctrl+A → Ctrl+C로 전체 복사해 창에 붙여넣고 정보 추출을 누르면 표로 정리됩니다. 값을 확인·수정한 뒤 적용하세요.
  • 주소만 붙여넣어도 됩니다. 이 경우 수집기가 실제 페이지를 읽어와 추출하므로, 수집기가 꺼져 있으면 본문 복사 방법을 안내합니다.

판매가 계산

  • 판매가 계산은 이미 불러온 상품의 구성 수량과 판매가를 다시 계산합니다. 1688에서 가져온 상품이면 단가·배송비가 자동으로 채워져 있고, 엑셀 상품은 단가를 직접 넣으면 그때부터 계산됩니다.
  • 표에서 수량을 클릭해 고르고 적용을 누르면 옵션·구성·수량·판매가가 함께 바뀝니다. 색상이 2개 이상이면 색상 믹스로 색상별 개수를 직접 정할 수 있고, 합계가 곧 구성 수량이 됩니다.
  • 표에는 수량별로 세트 원가 · 판매가 · 개당 판매가 · 순마진이 나옵니다.

기본 템플릿 (패션잡화 · 생활용품 · 홈인테리어)

문구·완구 템플릿

발랄한 키즈문구 스타일입니다. 배경 히어로(특징 배지 4개) → 특징 3컷 → 혜택 아이콘 5개 → POINT 1·2 → 놀이 3컷 → SIZE → PRODUCT INFO + KC → 경고 블록 → 구매 전 주의사항으로 구성되며, 원본 사진의 주조색을 뽑아 배경·배지 색이 자동으로 맞춰집니다.

  2. 상품을 고르면 색상 옵션이 자동 인식되어 대표 칸 이름이 "블루 D / 그레이 D"처럼 옵션별로 바뀝니다
  3. 각 칸에 해당 색상 원본 사진을 넣으면 상품명_블루 D.png 형식으로 저장됩니다
  4. 상세(견적서용)는 상품명 + 사진 3장 + 표시사항 표로 구성되어 상품명 S.png로 저장됩니다
  5. 표시사항 저장 (PNG)로 상품명·색상·수량·재질·제조국·제조자·수입자 표를 단독 이미지로 저장할 수 있습니다

모델 표현 (패션잡화)

  • 모델 없이 (기본) — 인물·신체가 전혀 나오지 않는 상품 단독 연출. 작은 상품이 손 대비 작아 보이는 것을 막아 줍니다.
  • 손·목·발 부분만 — 인물은 부분 컷만 사용합니다.
  • 얼굴 포함 — 20대 한국인 모델 착용컷을 허용합니다. AI 얼굴은 실존 인물이 아니며 컷마다 다르게 나올 수 있어, 얼굴 노출 컷은 자동으로 최소화됩니다.
작업 도중 다른 카테고리 탭으로 바꾸면 페이지가 초기화됩니다 (확인창이 뜨며 사진·태그는 유지됩니다).

4STEP 2 · 문구와 검색태그

문구를 먼저, 이미지는 그다음입니다. 화면의 문구가 AI 이미지 프롬프트에 그대로 들어가기 때문입니다. 문구 없이 상세 AI 생성을 누르면 AI 문구가 먼저 자동 생성됩니다.
  • 기본 문구 채우기 — AI 없이 무난한 기본 문구를 넣습니다 (무료).
  • AI 문구 생성 — 카테고리 톤이 반영된 전체 문구를 만듭니다 (문구·완구는 배지·말풍선·경고문까지).
  • 모든 문구는 미리보기에서 클릭해 바로 수정할 수 있습니다 (파란 점선 = 수정 가능). 상품명이 두 줄이 되어도 단어 중간에서 잘리지 않습니다.
  • 문구를 고친 뒤에는 해당 슬롯의 AI 재생성만 누르면 새 문구 기준으로 이미지가 다시 만들어집니다.

쿠팡 검색태그 20개

  • 평소에는 접혀 있습니다. 제목을 누르면 펼쳐집니다.
  • 상품을 불러오면 상품명을 기준으로 자동 생성됩니다. 태그 복사로 복사해 판매자센터에 붙여넣고, 마음에 들지 않으면 다시 생성하세요.
  • AI 추천 검색어이므로 실제 검색량은 판매자센터에서 교차 확인하는 것을 권합니다.

② 1688 이미지 후보 쓰기

1688에서 가져온 상품에는 이미지 후보 줄이 나타납니다. 사진을 따로 내려받을 필요가 없습니다.

  • 수집 대상은 옵션(SKU) 사진과 상세페이지 사진입니다. 같은 사진의 축소판이나 사이트 아이콘은 자동으로 걸러집니다.
  • 후보를 클릭하면 원본 사진에 추가되고, 다시 클릭하면 빠집니다. 원본 사진 쪽에서 ×로 지워도 후보의 체크가 함께 풀립니다.
  • 후보에 마우스를 올리면 600px로 크게 보입니다. 작은 썸네일만 보고 고르지 않아도 됩니다.
  • 사진 아래에 옵션 이름이 표시됩니다. 흔한 색상·사이즈는 한글로 바꿔 보여주고(粉色 → 핑크), 사전에 없는 말은 원문 그대로 둡니다.
  • 🔗 1688 상품 페이지 열기로 원본 페이지를 새 탭에서 바로 확인할 수 있습니다.

③ 대표이미지 — 원본 그대로가 기본

대표이미지는 AI가 아니라 원본 사진을 쓰는 것이 기본입니다. AI는 그림을 새로 그리기 때문에 실물과 100% 같아야 하는 대표이미지에는 맞지 않습니다.
  • 대표 원본 채우기 — 원본 사진을 D~D5에 순서대로 넣습니다. 저장하면 1000×1000 흰 배경으로 잘림 없이 변환되고 D 메인에 수량 배지가 합성됩니다.
  • 상세 이미지를 만들면 D1~D5가 자동으로 채워집니다. 직접 넣은 칸은 덮어쓰지 않으므로 D 메인만 채우면 됩니다.
  • 옵션(색상)이 2개 이상이면 D 메인 칸이 옵션 수만큼 늘어나고 칸마다 옵션명이 표시됩니다. D1~D5는 공용 1세트입니다.
  • 사이즈·크기 수정 — 모서리를 잡으면 비율 유지 확대·축소, 변을 잡으면 그 방향으로 늘리기, 안쪽 드래그로 위치 이동입니다. [좌우 반전] [상하 반전]으로 사진을 뒤집을 수도 있고, [원래대로]를 누르면 반전까지 함께 풀립니다.
  • 배경만 교체 (D 메인 전용) — 상품은 그대로 두고 배경만 AI로 바꿉니다. 마음에 들지 않으면 [되돌리기]로 복원하세요.
  • 수량 배지는 미리보기에도 저장본과 같은 모양으로 보이고, 크기를 작게·보통·크게 중에서 고를 수 있습니다.

④ 글자 지우기

  • 1688 사진에 흔한 중국어 라벨(黑色·米色 등)을 지우는 도구입니다. 채워진 칸 위의 [글자 지우기]로 엽니다.
  • 기본은 원형 지우개입니다. 글자 위를 문지르면 주변 색으로 메워지고, 크기는 1~10단계입니다. 넓은 영역은 [사각 박스] 모드가 편합니다.
  • AI를 쓰지 않아 무료이고 즉시 처리되며 상품 픽셀은 그대로입니다. 무늬가 복잡한 배경 위 글자는 메운 자국이 보일 수 있으니 결과를 확인하세요.

⑤ AI 연출 생성 (상세페이지용)

  • 상세 AI 생성 — 상세페이지의 빈 칸을 연출컷으로 채웁니다. 엑셀의 사이즈 값이 프롬프트에 들어가 크기감과 상품 간 비례가 반영되고, 사진에 없는 디자인을 지어내는 것을 막습니다.
  • 대표 AI 연출 — 연출된 대표가 필요할 때만 씁니다. D 메인을 AI로 만들고 D1~D5는 상세 이미지를 재사용합니다.
  • AI 재생성 — 이미지 위 버튼입니다. 요구사항("배경 밝게", "소품 제거")과 모델 표현을 이번 1회만 골라 그 칸만 다시 만듭니다.
  • 원본으로 채우기 — 빈 칸마다 있습니다. AI가 실패하거나 마음에 들지 않으면 누르는 즉시 원본 사진으로 대체됩니다 (누를 때마다 다음 사진).
  • 생성이나 재생성이 끝나면 "띵동" 소리로 알려 줍니다. 소리가 필요 없으면 기타의 [완료 소리]를 끄면 됩니다.
  • 세트 상품이어도 착용·사용·놀이컷에서는 대표 1개만 착용한 모습으로 만듭니다.

⑥ 사이즈컷

  • Size 칸에 원본 사진을 넣으면 엑셀의 사이즈 값이 치수선과 함께 자동 합성됩니다 (숫자 오타가 생길 수 없습니다).
  • 치수 편집 — 파란 점을 끌면 숫자가, 주황 점을 끌면 화살표의 길이·방향이 바뀝니다. 끝점은 360° 자유롭게 움직여 대각선 치수도 가능하고, 파란 점을 더블클릭하면 숫자를 직접 입력할 수 있습니다. 배경이 어두우면 선 색을 흰색으로 바꾸세요.
  • 사이즈 값을 고친 뒤에는 사진을 다시 넣어야 새 값으로 합성됩니다. 위치만 옮길 때는 사진을 다시 넣지 말고 [치수 편집]을 쓰세요.

⑦ 상품 옵션 칸

  • 옵션을 /로 2개 이상 적으면 "상품 옵션" 섹션이 옵션별 이미지 칸으로 바뀝니다 (한 줄 2개씩). 각 칸은 원본 사진 전용이며 아래에 옵션명과 KC인증번호가 표시됩니다.
  • 합친 구성(핑크+그린)은 구성 합치기로 구성별 사진을 1장씩 골라 한 장으로 합쳐 넣습니다. 기본 합성은 원본 그대로라 색이 변하지 않고 무료이며, [AI로 자연스럽게]는 비용이 들고 색이 조금 달라질 수 있습니다.
  • 미리보기 옵션 줄의 구성 조정으로 색상별 개수를 바꾸면 옵션·구성·수량·판매가가 함께 갱신됩니다.

⑧ 그 밖의 편의 기능

  • 채워진 이미지를 잡아 다른 칸으로 끌면 이동, 이미 채워진 칸으로 끌면 교환됩니다. 상세 칸과 대표 칸 사이도 됩니다.
  • [제거]로 지운 이미지는 그 칸에 보관되어 제거 복구로 되살릴 수 있습니다 (칸마다 최근 1장).
  • 이미지 일괄 넣기는 여러 장을 빈 칸에 순서대로 넣고, 이미지 모두 지우기는 전체를 비웁니다.
AI 생성 후 확인할 두 가지입니다. ① 구성 개수가 맞는지 (7자루가 8자루로 늘지 않았는지) ② 배경 소품이 구성품으로 오해될 만한지. 어긋나면 [AI 재생성] 또는 [원본으로 채우기]를 쓰세요.

8STEP 5 · 작업 파일 저장·수정

결과물 저장(STEP 4)이 납품용 파일이라면, 작업 파일은 다시 열어 고치기 위한 파일입니다.

  • 작업물 저장 — 작업 전체(상품 정보·이미지·문구·설정)를 파일 하나(.ktw)로 저장합니다. 이미지가 들어 있어 파일이 큽니다.
  • 작업물 수정하기 — 저장해 둔 .ktw 파일을 열어 그 상태에서 이어서 작업합니다. 다른 PC에서도 열리므로 인수인계에 그대로 쓸 수 있습니다.

11문제 해결 (FAQ)

1688 일괄 가져오기에서 "차단됨"이 나옵니다

1688이 자동 접속을 막은 상태입니다. 수집기는 즉시 멈추고 15분 쉬며(반복되면 30·60분), 남은 주소는 입력칸에 되돌려 둡니다. 냉각이 끝나면 [이어서 가져오기]를 누르세요. 그 사이에는 1688 페이지를 직접 열어 [1688 개별 가져오기]로 처리하면 됩니다. 냉각 중에 계속 다시 누르면 차단이 길어집니다.

"슬라이더 확인 필요"가 떴습니다

1688이 사람인지 확인하는 화면입니다. 수집기가 띄운 Edge 창이 앞으로 나오니 슬라이더를 한 번 밀어 주세요. 그 뒤 자동으로 이어서 진행하고, 통과 기록이 남아 다음 상품부터는 대개 뜨지 않습니다. 10분 안에 풀지 않으면 중단되며 남은 주소는 보관됩니다.

수집기가 꺼져 있다고 나옵니다

PC에서 1688수집기.exe를 더블클릭해 실행한 뒤 창을 다시 여세요. 처음 쓰는 PC라면 창 안의 [수집기 다운로드]로 받으면 됩니다. 검은 창을 닫으면 수집기가 종료되니 작업 중에는 켜 두세요.

이미지 후보가 안 보이거나 클릭해도 안 들어갑니다

페이지를 새로고침해 최신 버전인지 확인하세요. 1688로 가져온 상품에만 후보가 표시되며, 엑셀로 넣은 상품에는 나타나지 않습니다.

대표이미지가 실물과 달라 보입니다

대표는 대표 원본 채우기를 쓰세요. 원본 사진 그대로라 변형이 없습니다. AI 연출 대표는 분위기가 필요할 때만 보조로 쓰는 것이 좋습니다.

AI가 상품의 앞뒤를 똑같이 만듭니다

뒷면 사진을 추가하고 라벨을 뒷면으로 지정하세요. 라벨이 있으면 AI가 뒷면을 지어내지 않습니다.

"이미지 모델은 결제 활성화 후 사용 가능합니다"가 뜹니다

API 키가 무료 등급입니다. AI Studio에서 결제를 연결하거나 유료 프로젝트의 키로 바꾸세요. 활성화 직후에는 반영까지 몇 분 걸릴 수 있습니다.

AI 생성이 실패하거나 계속 마음에 안 듭니다

빈 칸의 원본으로 채우기가 가장 빠릅니다. 재시도보다 확실합니다.

문구를 고쳤는데 이미지에 반영되지 않습니다

문구를 고친 뒤 그 칸의 [AI 재생성]을 누르면 새 문구 기준으로 다시 만들어집니다. 프로그램을 껐다 켜거나 키를 다시 넣을 필요는 없습니다.

사이즈컷 치수가 갱신되지 않습니다

사이즈 값을 고친 뒤에는 사진을 다시 넣어야 새 값으로 합성됩니다. 숫자·화살표의 위치만 바꾸려면 [치수 편집]을 쓰세요.

옵션 칸이 나타나지 않습니다

옵션(또는 색상) 값이 /로 구분되어 있어야 합니다 (쉼표는 안 됩니다). 예: 블루 / 그레이 / 핑크. 옵션이 1개면 기존의 단일 구성 칸이 유지됩니다.

판매가 계산에서 "2만 원 미만으로는 마진이 나오지 않습니다"가 뜹니다

단가가 높아 그 수량으로는 목표 순마진을 만들 수 없다는 뜻입니다. 수량을 줄이거나 단가·환산율을 확인하세요.

구글시트를 불러오지 못합니다

시트가 "링크가 있는 모든 사용자 — 뷰어" 공개인지, '템플릿 예시' 탭이 있는지 확인하세요.

파일이 하나만 받아집니다

브라우저의 다중 다운로드 차단입니다. 주소창 오른쪽 아이콘에서 "항상 허용"으로 바꾸세요. [3종 한 번에 저장]은 파일이 하나라 이 문제가 없습니다.

실수로 새로고침해서 작업이 날아갔습니다

다시 접속하면 이전 작업 복구 안내가 뜹니다 (3분 간격 자동 저장, 같은 PC·브라우저, 저장 후 3일 이내). 안내가 없으면 STEP 5의 [작업물 수정하기]로 저장해 둔 작업 파일을 여세요.
