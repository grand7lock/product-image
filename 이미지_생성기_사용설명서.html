1시작하기 — API 키 (처음 쓰는 분 상세 가이드)

AI 기능(상품명 다듬기, 카피, 검색태그, 이미지 생성)을 쓰려면 구글의 API 키가 필요합니다. 키는 "구글 AI를 쓸 수 있는 출입증" 같은 것으로, 한 번만 발급받아 생성기에 저장해두면 됩니다. 키 없이도 엑셀 업로드 · 사진 삽입 · 대표 원본 채우기 · 사이즈컷 합성 · 저장은 모두 작동합니다.

1단계. 구글 AI 스튜디오 접속

  1. 크롬에서 aistudio.google.com/apikey 접속 (이 링크가 바로 키 관리 화면입니다)
  2. 구글 계정으로 로그인 — 지메일 계정이면 됩니다. (회사 계정은 관리자가 API를 막아둔 경우가 있으니 안 되면 개인 계정 사용)
  3. 처음 접속이면 약관 동의 화면이 나옵니다 → 동의하고 진행

2단계. API 키 만들기

  1. 키 관리 화면(한국어면 좌측 메뉴 "API 키")에서 우측 상단 API 키 만들기 (영어: Create API key) 클릭
  2. 프로젝트를 고르라고 하면 "새 프로젝트에서 생성" 선택 → 잠시 후 AQ. 또는 AIza로 시작하는 긴 문자열이 만들어집니다 — 이것이 키입니다
  3. 키 오른쪽의 복사 아이콘(📋)을 눌러 복사
키는 비밀번호처럼 취급하세요 — 카톡·문서에 공유하지 말고, 각자 자기 키를 발급받는 것을 권장합니다. 키가 유출되면 그 사람이 쓰는 요금이 내 카드로 청구됩니다.

3단계. 결제 활성화 — 이미지 생성에 필수

왜 필요한가: 텍스트 기능(카피·태그·상품명)은 무료로 작동하지만, 이미지 생성은 구글이 결제 등록된 프로젝트에만 허용합니다. 카드만 등록해두는 종량제라서 등록 자체로는 요금이 나가지 않고, 이미지 1장당 수십 원씩만 청구됩니다.

  1. 같은 키 관리 화면의 키 목록에서 내 키의 "결제 등급" 열을 봅니다
  2. "무료(Free)"로 표시되어 있으면 → 그 행의 "결제 설정"(Set up billing) 버튼 클릭
  3. Google Cloud 결제 화면이 열리면: 국가(대한민국) 선택 → 카드 정보 입력 → 완료
  4. 몇 분 뒤 키 목록에서 결제 등급이 "유료(Paid)"로 바뀌면 성공입니다 (바로 안 바뀌면 5~15분 기다렸다 새로고침)
가장 흔한 실수: 결제를 A 프로젝트에 연결해놓고 B 프로젝트의 키를 쓰는 경우입니다. 키는 프로젝트에 소속되므로, 결제 등급이 "유료(Paid)"로 표시되는 바로 그 키를 복사해서 써야 합니다. 유료 프로젝트가 따로 있다면 그 프로젝트를 선택해 새 키를 만드세요.

4단계. 생성기에 키 등록

  1. 생성기 접속 → 사이드바 맨 위 "Google AI Studio API Key" 입력란 클릭
  2. 복사해둔 키 붙여넣기 (Ctrl+V) → 저장 클릭
  3. 버튼 옆에 "저장됨"이 표시되면 완료 — 다음부터는 자동으로 입력되어 있습니다
  • 키는 지금 쓰는 PC의 브라우저에만 저장되고 외부로 전송되지 않습니다. 다른 PC에서 쓰려면 그 PC에서 같은 키를 한 번 더 등록하면 됩니다 (같은 키를 여러 PC에서 동시에 써도 됩니다)
  • 키 교체: 새 키를 붙여넣고 저장. 키 삭제: 입력란을 비우고 저장
  • 공용 PC에서는 저장하지 마세요

5단계. 잘 됐는지 확인

  1. 엑셀(또는 시트)로 상품 하나를 불러온 뒤 STEP 2의 AI 문구 생성 클릭 → 문구가 생성되면 키 자체는 정상입니다
  2. STEP 3의 상세 AI 생성을 눌렀을 때 "결제 활성화 후 사용 가능" 메시지가 나오면 → 3단계(결제)가 아직 안 된 것입니다
요금이 얼마나 나가는지는 aistudio.google.com 좌측 메뉴의 사용량 / 지출에서 언제든 확인할 수 있습니다. 상품 1개 풀 작업 기준 약 400~700원 수준입니다.

3대량 작업 (최대 20개)

엑셀에 상품이 2개 이상이면 사이드바에 상품 목록이 자동으로 나타납니다.

  • 행 클릭 = 그 상품으로 전환. 이미지·문구·태그·카테고리·모델 설정이 상품별로 자동 보존됩니다.
  • 각 행에 사진 수 + 상태 표시: 대기 → 작업중 → 저장됨.
  • 미리보기 상단 바의 ← 이전 다음 →으로 순서 이동.

권장 흐름 (상품당 3~4분)

엑셀 업로드→NO 선택→원본 사진 넣기→대표 원본 채우기→상세 AI 생성→검토·재생성→저장 3종→다음 NO
작업 상태는 브라우저 메모리에만 있습니다. 새로고침·창 닫기 시 저장 안 한 작업이 사라집니다 (경고창은 뜸). 상품마다 저장 후 넘어가세요.

4카테고리와 템플릿

탭 4개(👜 패션잡화 / ✏️ 문구·완구 / 🧺 생활용품 / 🛋️ 홈인테리어)는 지금 작업 중인 상품 하나에 적용되는 설정이며 상품별로 기억됩니다.

기본 템플릿 (패션잡화·생활용품·홈인테리어)

모노톤 스타일: 히어로 → 소개 → 포인트 01~04 → 착용·사용컷 → 상품 옵션(v1.26: 옵션 여러 개면 이미지 칸이 한 줄 2개씩 자동 확장) → Size(v1.27: 상품 옵션 아래로 이동, 옵션 칸과 같은 반폭 크기) → Product Info → 주의사항.

문구·완구 전용 템플릿

발랄한 키즈문구 스타일: 배경 히어로(특징 배지 4) → 특징 3컷 → 혜택 아이콘 5 → POINT 1·2(컬러 칩) → 놀이 3컷 → SIZE(최대 3칸) → PRODUCT INFO + KC → 경고 블록 → 구매 전 주의사항(최하단). 원본 사진을 넣으면 사진의 주조색을 추출해 배경·배지 색이 자동으로 바뀝니다.

🚀 로켓 이미지 (v1.21 신설)

로켓 견적서용 산출물을 만드는 전용 모드입니다. 다른 카테고리와 다르게 구글시트에서 상품을 불러옵니다:

  1. 로켓 탭 선택 → STEP 1에 나타나는 입력란에 구글시트 주소 붙여넣기 → 시트 불러오기 ('템플릿 예시' 탭의 상품 전부, 시트는 링크 공개 상태여야 함. 주소는 저장되어 다음부터 자동 입력)
  2. 상품 목록에서 선택 — 색상 옵션이 자동 인식되어 대표 칸 이름이 "블루 D / 그레이 D / 핑크 D"처럼 옵션별로 바뀝니다
  3. 각 옵션 칸에 해당 색상 원본 사진을 드래그/클릭으로 넣기 → 저장 시 상품명_블루 D.png 형식
  4. 상세(견적서용)는 상품명 타이틀 + 사진 3장 + 표시사항 표 구성 → 상품명 S.png
  5. 표시사항 저장 (PNG) — 상품명/색상/수량/재질/제조국/제조자({브랜드} OEM)/수입자({브랜드}) 표를 단독 이미지로 저장 → 상품명 표시사항.png

모델 표현 토글 (패션잡화 전용, v1.20)

패션잡화 탭을 선택하면 STEP 2에 토글이 나타납니다:

  • 손·목·발 부분만 (기본) — 인물은 부분 컷만
  • 얼굴 포함 모델 — 20대 한국인 모델이 착용한 컷 허용. AI 얼굴은 실존 인물이 아니며 컷마다 다르게 나올 수 있어, 얼굴 노출 컷은 자동으로 최소화됩니다
작업 중 템플릿이 다른 카테고리로 탭을 바꾸면 페이지가 초기화됩니다 (확인창 표시, 사진·태그 유지).

5STEP 2 · 문구와 검색태그

v1.26부터 문구가 STEP 2, 이미지가 STEP 3입니다. 포인트 설명·구성 정보 등 화면의 문구가 AI 이미지 프롬프트에 그대로 들어가기 때문에, 문구를 먼저 완성해야 이미지가 정확하게 나옵니다. 문구를 채우지 않고 상세 AI 생성을 누르면 AI 문구가 자동으로 먼저 생성됩니다.
  • 기본 문구 채우기 — AI 없이 무난한 기본 문구.
  • AI 문구 생성 — 카테고리 톤이 반영된 전체 문구 (문구·완구는 배지·말풍선·경고문까지).
  • 모든 문구는 미리보기에서 클릭해 바로 수정 (파란 점선 = 수정 가능). 문구 수정 후에는 해당 슬롯의 [AI 재생성]만 누르면 반영됩니다 — 프로그램을 껐다 켤 필요가 없습니다.

쿠팡 검색태그 20개

  • 엑셀 업로드 시 자동 생성 → 태그 복사 → 판매자센터에 붙여넣기. 다시 생성 가능.
  • AI 추천 검색어이므로 실제 검색량은 판매자센터에서 교차 확인 권장.

② 대표이미지: 원본 그대로 (권장, v1.20 신설)

대표이미지는 AI가 아니라 원본 사진을 쓰는 것이 기본입니다. AI는 그림을 새로 그리기 때문에 대표이미지처럼 실물과 100% 같아야 하는 곳에는 맞지 않습니다.
  • 대표 원본 채우기 — 원본 사진을 D~D5에 순서대로 배치합니다. 저장 시 1000×1000 흰배경으로 잘림 없이 변환되고 D 메인에 수량 배지가 합성됩니다. 상품 픽셀은 원본 그대로 — 변형 0%.
  • 특정 칸만 다른 사진으로: 그 칸 클릭 → 직접 선택.
  • [사이즈·크기 수정] (v1.26 신설, v1.27 명칭 변경) — 대표 칸 이미지 좌하단 버튼. 모서리를 잡으면 비율 유지 확대·축소, 상하좌우 변을 잡으면 그 방향으로 늘리기, 안쪽 드래그로 위치 이동 → [적용] 시 1000×1000으로 재합성됩니다.
  • [배경만 교체] (v1.26 신설, D 메인 전용) — D 메인 이미지의 [AI 재생성] 아래 보라 버튼. 상품은 그대로 두고 배경만 AI로 교체합니다 (스타일 직접 입력 가능). 결과가 마음에 안 들면 우하단 [되돌리기]로 원본 복원. ※ AI 특성상 미세한 차이가 생길 수 있으니 생성 후 원본과 비교하세요.
  • 옵션별 대표 (v1.26 신설) — 색상(옵션)을 / 로 2개 이상 적으면 D 메인 칸이 옵션 수만큼 늘어나고 칸마다 옵션명이 표시됩니다. v1.27: 옵션 D 메인들이 맨 위에 먼저 나열되고 D1~D5가 그 뒤를 따릅니다. 각 칸에 해당 옵션 원본을 넣으세요. D1~D5는 공용 1세트 그대로입니다.
  • 수량 배지 미리보기 (v1.27 신설) — 저장 시 합성되는 수량 배지(예: "2개")가 D 메인 칸 미리보기에도 같은 모양으로 표시됩니다. 수량 값을 고치면 즉시 반영됩니다.

⑤ 상품 옵션 칸 (v1.26 신설, 기본 템플릿)

  • 색상(옵션)을 / 로 구분해 2개 이상 적으면 "상품 옵션" 섹션이 옵션별 이미지 칸(한 줄 2개씩, 3개면 위 2 + 아래 1)으로 바뀝니다.

⑥ 슬롯 간 이미지 이동/교환 (v1.26 신설)

10문제 해결 (FAQ)

대표이미지가 실물과 달라져요

대표는 대표 원본 채우기를 쓰세요 — 원본 사진 그대로라 변형이 없습니다. AI 연출 대표는 분위기가 필요할 때만 보조로.

AI가 상품의 앞뒤를 똑같이 만들어요

뒷면 사진을 추가하고 라벨을 뒷면으로 지정하세요. 라벨이 지정되면 AI가 뒷면을 지어내지 않습니다.

"이미지 모델은 결제 활성화 후 사용 가능합니다"라고 떠요

키가 무료 티어입니다. AI Studio에서 결제 계정을 연결하거나 Paid 프로젝트의 키로 교체하세요. 활성화 직후엔 반영까지 몇 분 걸릴 수 있습니다.

AI 생성이 실패하거나 몇 번을 해도 마음에 안 들어요

빈 슬롯의 [원본으로 채우기]로 즉시 대체하세요. 재시도보다 빠르고 확실합니다.

사이즈컷 치수가 갱신되지 않아요

사이즈 값을 고친 뒤에는 사이즈컷에 사진을 다시 넣어야 새 값으로 합성됩니다. 숫자·화살표의 위치만 바꾸고 싶으면 사진을 다시 넣을 필요 없이 [치수 편집]을 쓰세요.

문구를 고쳤는데 이미지에 반영이 안 돼요

문구를 수정한 뒤 해당 슬롯의 [AI 재생성]을 누르면 새 문구 기준으로 다시 만들어집니다. 프로그램을 껐다 켜거나 API 키를 다시 넣을 필요가 없습니다.

옵션 칸이 안 나타나요

색상 값에 / 구분이 있어야 합니다 (쉼표 아님): 블루 / 그레이 / 핑크. 기본 템플릿(패션잡화·생활용품·홈인테리어)에서만 옵션 칸이 나타나며, 옵션 1개면 기존 단일 구성 칸이 유지됩니다.

구글시트를 못 불러와요

① 시트가 "링크가 있는 모든 사용자 — 뷰어" 공개인지 확인하세요. ② v1.22부터는 생성기를 파일로 열어도(더블클릭) 자동 우회 방식으로 불러옵니다 — 구버전이면 최신 파일로 교체하세요. ③ 그래도 안 되면 인터넷 연결과 시트에 '템플릿 예시' 탭이 있는지 확인.

파일이 1개만 받아지고 나머지가 안 받아져요

브라우저의 다중 다운로드 차단입니다. 주소창 오른쪽 아이콘에서 "항상 허용"으로 바꾸세요.

실수로 새로고침해서 작업이 날아갔어요

다운로드된 파일은 남아 있습니다. 엑셀을 다시 업로드하고 저장 안 된 상품만 재작업하세요.

11버전 수정 이력

v1.27 (2026-08-29)

  • [글자 지우기] — 모든 슬롯에서 중국어 라벨 등을 드래그 박스 지정으로 제거 (주변 색 보간, 비AI·무료, 반복 지정·되돌리기 지원).
  • Size 섹션 이동·축소 — 상품 옵션 아래로 이동, 옵션 칸과 같은 반폭 크기(여러 개면 한 줄 2개). 치수 글자는 축소 보정으로 확대.
  • 수량 배지 미리보기 — 저장 전에도 D 메인 칸에 수량 배지가 보입니다.
  • 대표 나열 순서 — 옵션이 여러 개면 D 메인들(옵션별)이 맨 위에 먼저, D1~D5가 그 뒤에.
  • 저장 표기 정리 — '대표이미지 저장 (6장)' → '대표이미지 저장' (옵션 수 + D1~D5 전부 한 번에 저장됨은 기존과 동일).
  • 대표 칸 버튼 정리 — '수정' → '사이즈·크기 수정', '배경 교체' → '배경만 교체'(AI 재생성 아래로 이동), [되돌리기]는 우하단.
  • 이미지 모드 기본값 — AI(기본) + 원본(보조)가 기본이 되고 라벨에 괄호 표기. 기존 사용 PC도 1회 자동 전환(이후 선택 유지).
  • 버튼 순서 — STEP 1: [엑셀 업로드]가 앞으로 / STEP 2: [AI 문구 생성]이 앞으로.
  • STEP 3 구조 개편 — 📷 원본 사진(공통 재료) · 🖼 상세 이미지 만들기 · ⭐ 대표 이미지 만들기 세 그룹으로 구분.

v1.26 (2026-08-28)

  • STEP 재배치 — STEP 2 = 문구, STEP 3 = 이미지 ('카피' 용어를 '문구'로 통일). 문구가 기본 상태로 상세 AI 생성을 누르면 AI 문구를 먼저 자동 생성.
  • 상품 옵션 칸 — 색상(옵션)을 / 로 구분하면 "상품 옵션" 섹션이 옵션별 이미지 칸(한 줄 2개씩)으로 확장. 이미지 아래 옵션명 + 인증번호(/ 구분) + KC마크 자동 표시. 원본 삽입 전용.
  • 옵션별 대표 — 옵션 수만큼 D 메인 칸이 늘어나고, 저장 파일명이 {상품번호} {상품명}_{옵션} D.png.
  • D 메인 [배경 교체] — 상품은 유지하고 배경만 AI로 교체 (스타일 입력 가능, [되돌리기] 지원).
  • 대표 [수정] — 모서리(비율)·변(늘리기) 핸들 8개 + 이동으로 대표 이미지를 편집.
  • [치수 편집] — 사이즈컷의 치수 숫자와 화살표 끝점을 드래그로 이동, 화살표 길이 조절.
  • 사이즈컷 개선 — 치수 숫자의 흰 박스 제거(숫자만), 화살표 얇게, 미리보기에서 전체 표시.
  • 버그 수정 — 사이즈 안내 문구가 저장 PNG에 포함되던 문제 해결.
  • 슬롯 간 이미지 이동/교환 — 이미지를 잡아 다른 슬롯으로 드래그.
  • 히어로 [문구 위치] — 제목 블록을 상단/중앙/하단으로 이동.
  • 구매 전 주의사항 — 가운데 정렬 + 자연스러운 줄바꿈.
  • AI 프롬프트 강화 — 사이즈 값 자동 주입(크기감·비례), 창작 디자인 금지 강화.
